# Parity — local evidence command center

A complete Windows demonstration of monitored websites, immutable versions, semantic retrieval, and cited chat. React/TypeScript frontend, FastAPI backend, SQLite, local MiniLM, isolated Chromium, and free local Qwen.

Start with **QUICK_START.md**, then follow **PRESENTATION_WALKTHROUGH.md**. Setup once with `setup.bat`; launch with `start.bat`. Compiled frontend assets are included. No Node runtime or paid API is required to present.

See **VERIFICATION_REPORT.md** for measured results and limitations, and **THIRD_PARTY_NOTICES.md** for dependency notices. The original CLI, REST endpoints, and five MCP tools remain available.
